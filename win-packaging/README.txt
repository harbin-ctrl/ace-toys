win-toys for Windows

The Ace toys, ported to Windows: Splat, Poingo and Balloons.

Install
  Double-click install.cmd. It installs for the current user only, so no
  administrator rights are needed:
    %LOCALAPPDATA%\Programs\win-toys\   the toys and the DLLs they use
    Start menu > Ace                    one shortcut per toy
  Quit a toy before installing over it.

Uninstall
  Double-click uninstall.cmd.

Logs
  A toy started from the Start menu writes its messages to
  %LOCALAPPDATA%\<toy>\session.log
